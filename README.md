# شجرة العشيرة

موقع لتسجيل أنساب العشيرة وعرضها كشجرة تفاعلية، يضيف فيه كل فرد اسمه ونسبه ويربطه النظام بأجداده تلقائياً، مع لوحة تحكم كاملة للإدارة والمراجعة والإحصاءات.

---

## التشغيل

### الطريقة الأسهل (على هذه الحاسبة)
انقر مرتين على **`run.bat`** فيفتح الموقع على `http://localhost:8080`.
يستخدم PHP الموجود في `C:\xampp\php` تلقائياً. أبقِ النافذة السوداء مفتوحة ما دام الموقع يعمل.

> يمكن لأي هاتف متصل بالشبكة نفسها (الواي فاي) فتح الموقع عبر `http://عنوان-الحاسبة:8080`.

### عبر XAMPP (Apache)
انسخ المجلد كاملاً إلى `C:\xampp\htdocs\family-tree` وشغّل Apache من لوحة XAMPP، ثم افتح `http://localhost/family-tree`.

### على استضافة إنترنت
ارفع الملفات إلى الاستضافة (أي استضافة تدعم PHP 8 أو أحدث، ومعظم الاستضافات المشتركة تدعمه). لا يحتاج الموقع إلى قاعدة MySQL، فقاعدة البيانات ملف واحد يُنشأ تلقائياً داخل `data/`.
- يجب أن يكون مجلد `data/` قابلاً للكتابة.
- ملفات `.htaccess` المرفقة تمنع الوصول إلى قاعدة البيانات وملفات النظام.
- يُنصح بتفعيل HTTPS (شهادة مجانية من الاستضافة).

### GitHub
المستودع يحفظ **الكود فقط**. قاعدة البيانات (`data/clan.sqlite`) مستثناة في `.gitignore` حتى لا تُرفع أسماء العشيرة وأرقام الهواتف.
GitHub Pages يعرض الصفحات الثابتة فقط ولا يشغّل PHP، لذلك يعمل الموقع من نسخة تُنزَّل من المستودع على حاسبة أو استضافة تدعم PHP:
```
git clone <رابط المستودع>
```
ثم شغّل `run.bat` أو انسخ المجلد إلى `htdocs`.

## أول تشغيل
يفتح **معالج التهيئة** تلقائياً، وفيه تحدد:
1. عنوان الموقع، والقبيلة، والعشيرة، والفخذ، وألقاب العشيرة (مثل: الحلفي، الحلافي).
2. اسم **الجد الأكبر** (جذر الشجرة).
3. حساب **المالك** (اسم المستخدم وكلمة المرور).
4. خيار إضافة بيانات تجريبية لاستعراض الشجرة، ويمكن حذفها لاحقاً من: الإعدادات ← النظام ← تفريغ الشجرة.

لوحة التحكم على الرابط `/admin`.

---

## خطة العمل المقترحة للعشيرة
1. **المشرف يبني الهيكل الأساسي**: الجد الأكبر، ثم الأجداد المعروفون، ثم رؤوس البيوت (من صفحة «الأفراد» أو بالضغط على أي اسم في الشجرة).
   ولإضافة جد أعلى من الجد الحالي (لإكمال السلسلة حتى الجد الحادي عشر أو أبعد) استخدم «إضافة جد أعلى» في صفحة الأفراد.
2. **تحديد البيوت**: من صفحة «البيوت» تختار رأس البيت وتعطيه اسماً ولوناً، مثل «بيت محمد الموسى». يظهر كل بيت في القائمة الجانبية وله شجرة خاصة به.
3. **رمز لكل بيت**: من صفحة «رموز البيوت» أنشئ رمزاً لرأس كل بيت وأرسله له بزر واتساب. صاحب الرمز يضيف أفراد بيته ويعدّل بياناتهم داخل بيته فقط، وكل ما يفعله يُسجَّل باسمه.
4. **نشر رابط الإضافة** (`/add.php`) في مجموعات العشيرة. يكتب كل شخص اسمه الخماسي أو السداسي، ويقترح عليه النظام نقطة الربط مع نسبة التطابق.
5. **المراجعة**: الطلبات من غير رمز تنتظر الاعتماد في صفحة «الطلبات». يعتمدها المشرف، أو رأس البيت إن أعطيته صلاحية الاعتماد.

## الربط الذكي
- يفصل الاسم الكامل إلى سلسلة (أنت ← الأب ← الجد ← …)، مع دمج الأسماء المركبة مثل «عبد الحليم» و«مال الله» و«زين العابدين»، وحذف «بن» ولقب العشيرة من آخر الاسم.
- يتسامح مع اختلاف الكتابة: «عبدالله» و«عبد الله»، «إبراهيم» و«ابراهيم»، «مصطفى» و«مصطفي»، «فاطمة» و«فاطمه»، و«ال» التعريف، وخطأ حرف واحد في الأسماء الطويلة.
- يبحث عن أعمق جد موجود يطابق تسلسل الأسماء، ويعرض الاحتمالات مرتبة إذا تشابهت الأسماء (مثل وجود أكثر من «محمد»)، وينبّه عند اختلاف اسم أحد الأجداد.
- إن لم يجد المستخدم نسبه يستطيع أن يختار جده يدوياً، أو يرسل طلبه دون ربط ليتولى المشرف ربطه.
- عند الاعتماد يُدمج المكرر تلقائياً (مثلاً إذا أضاف أخوان أباهما مرتين). وللمشرف أداتا «دمج» و«نقل» لفصل الأشخاص أو جمعهم لاحقاً.

## شكل الشجرة والألوان
- **نازلة**: الجد الأكبر في الأعلى والأجيال تتفرع نحو الأسفل، مع مسطرة ثابتة تبيّن رقم كل جيل.
- **طبيعية**: جذع في الأسفل عليه ألواح الأجداد، وفوقه «الجد الجامع»، ثم تاج من الأغصان والأوراق كلوحات الأنساب المطبوعة.
- **التلوين**:
  - حسب الجيل (الافتراضي): لون لكل جيل، مع دليل ألوان أسفل الشجرة.
  - كلاسيكي: رؤوس البيوت ذهبي، والأبناء أبيض، والأحفاد أوراق خضراء.
  - حسب البيت: لون لكل بيت.
- رؤوس البيوت تظهر بتاج وإطار ذهبي، والطلبات غير المعتمدة بإطار منقط.
- كل الألوان قابلة للتعديل من: الإعدادات ← الشجرة والألوان.
- **التصدير**: صورة PNG أو ملف SVG للطباعة الكبيرة على شكل لوحة، فيها العنوان والآيتان في إطارين مزخرفين ودليل الألوان وسطر الإهداء.

## الحماية من العبث والأسماء الوهمية
| الإجراء | التفاصيل |
|---|---|
| طرق الإضافة | مفتوحة مع المراجعة، أو برموز البيوت فقط، أو مغلقة |
| رموز البيوت | نطاق محدد لكل رمز، وصلاحيات (إضافة/تعديل/حذف/اعتماد)، وحد أقصى للإضافات، وتاريخ انتهاء، وإمكانية تعطيله أو تجديده |
| سجل العمليات | من أضاف ومن عدّل ومن حذف، ومتى، ومن أي جهاز وعنوان IP، مع عرض البيانات قبل التعديل وبعده |
| التراجع | استعادة المحذوف، والتراجع عن التعديل أو النقل بضغطة واحدة |
| حدود المحاولات | تحديد عدد محاولات إدخال الرموز ودخول المشرفين وإرسال الطلبات |
| أخرى | فخ للروبوتات، وكلمات محظورة، ومنع تكرار الاسم تحت الأب نفسه، وحماية النماذج من التزوير (CSRF) |

## لوحة التحكم
- **لوحة المعلومات**: أعداد الأفراد والبيوت والأجيال والطلبات، والزوار يومياً، والأجهزة، وآخر العمليات، وأكثر المساهمين.
- **الطلبات والاقتراحات**: اعتماد الطلبات أو رفضها أو تغيير نقطة ربطها، واقتراحات التصحيح التي يرسلها الزوار.
- **الأفراد**: البحث بالنسب، وتعديل كل الحقول، والنقل والدمج والحذف، وسجل كل شخص، والتصدير إلى Excel.
- **البيوت**: الإنشاء والألوان، وعدد الأفراد والأجيال في كل بيت، ورموز كل بيت.
- **رموز البيوت**: الإنشاء والإرسال عبر واتساب، وعدد مرات الدخول والإضافات والتعديلات لكل رمز.
- **سجل العمليات**: تصفية حسب الفاعل والعملية والتاريخ، مع الاستعادة والتراجع.
- **الزوار والأجهزة**: المتصلون الآن، والزوار يومياً وحسب الساعة، ونوع الجهاز ونظام التشغيل والمتصفح وطراز الهاتف، ومصادر الزيارات، ومن دخل برمز.
- **الإعدادات**: بيانات العشيرة وسلسلة الانتماء، والتسجيل والحماية، والألوان، والآيات، والنسخ الاحتياطي.
- **المشرفون**: ثلاثة أدوار هي المالك والمشرف العام والمحرر.

## النسخ الاحتياطي
من الإعدادات ← النظام: تحميل نسخة كاملة من قاعدة البيانات (ملف `.sqlite`)، أو الشجرة بصيغة JSON، أو الأفراد مع النسب بصيغة CSV تفتح في Excel.
للاستعادة: أوقف الموقع ثم ضع النسخة مكان `data/clan.sqlite`.

## الملفات
```
index.php        الصفحة الرئيسية
tree.php         الشجرة التفاعلية (الشجرة كاملة أو بيت محدد: ?root=رقم)
add.php          معالج «أضف نسبك»
api.php          واجهة البيانات
install.php      معالج التهيئة الأولى
admin/           لوحة التحكم
includes/        منطق النظام (الأسماء، الربط، الصلاحيات، السجل، الزوار)
assets/          التصميم والسكربتات (tree.js محرك رسم الشجرة)
data/            قاعدة البيانات (محمية)
```
