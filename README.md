# شجرة العشيرة — على Firebase

الموقع كاملاً على Firebase: الاستضافة، قاعدة البيانات، وتسجيل الدخول. لا يحتاج تشغيل أي حاسبة.

- **الموقع:** https://alistar1985.github.io/tree/ (وأيضاً https://clan-tree-halaf.web.app)
- **لوحة التحكم:** https://clan-tree-halaf.web.app/admin (للمالك فقط، ولا يظهر رابطها للزوار)
- **مشروع Firebase:** `clan-tree-halaf` (الاسم الظاهر: Clan tree)

## أين تُحفظ البيانات؟
في **Firebase Realtime Database** (أوروبا): الأسماء، البيوت، الطلبات، الرموز، سجل العمليات، الزوار، والإعدادات.
لا شيء يُحفظ على حاسبتك. النسخة الاحتياطية: لوحة التحكم ← الإعدادات ← النسخ الاحتياطي.

### تقليل الاستهلاك
- الشجرة والإعدادات تُحفظ في متصفح كل زائر مع «رقم نسخة».
- عند كل زيارة يُقرأ رقم النسخة فقط (بضعة بايتات)، ولا تُنزَّل الشجرة إلا إذا تغيّرت.
- الصفحة المفتوحة تفحص التحديثات كل دقيقة، فتتحدث الشجرة تلقائياً عند أي إضافة.
- الزوار يقرؤون بطلبات قصيرة دون اتصال دائم، فلا يُستهلك حد الاتصالات المتزامنة في الخطة المجانية.

## الحماية (قواعد قاعدة البيانات)
| من | ماذا يستطيع |
|---|---|
| الزائر | قراءة الشجرة، وإرسال طلب إضافة (يبقى معلقاً)، وإلغاء طلبه |
| رمز البيت | الإضافة والتعديل داخل بيته فقط، حسب صلاحياته |
| رمز المشرف | الإضافة والتعديل والحذف واعتماد الطلبات في الشجرة كاملة، دون لوحة التحكم |
| المالك والمشرفون | كل شيء، مع سجل كامل لكل عملية |

القواعد تُفرض على خادم Firebase نفسه، فلا يمكن تجاوزها من المتصفح.

## خطة العمل المقترحة للعشيرة
1. ابنِ الهيكل: الجد الأكبر، ثم البيوت (صفحة «البيوت»: اكتب اسم رأس البيت مباشرة).
2. أنشئ «رمز بيت» لرأس كل بيت، و«رمز مشرف» لمن يساعدك، وأرسلها بزر واتساب.
3. انشر رابط الموقع في مجموعات العشيرة: يفتح على الشجرة، وفيه زر «أضف نسبك».
4. راجع الطلبات واعتمدها. ما لا يُعثر على أجداده يُضاف فرعاً منقطاً يكتمل تلقائياً عندما يضيف أقاربه أنسابهم.

## وضع الصيانة
لوحة التحكم ← الإعدادات ← الصيانة: يرى الزوار صفحة «الموقع قيد الصيانة» برسالتك، وتعمل أنت كالمعتاد.

## الملفات
```
الموقع في جذر المستودع (GitHub Pages و Firebase Hosting)
index.html          الشجرة
add.html            أضف نسبك
admin.html          لوحة التحكم
setup.html          التهيئة الأولى (مرة واحدة)
assets/js/store.js  محرك البيانات: الربط الذكي، الطلبات، الرموز، السجل، الذاكرة المؤقتة
assets/js/tree.js   محرك رسم الشجرة
tools/build-rules.mjs مولّد قواعد الحماية → database.rules.json
php-version/          النسخة السابقة (PHP) للمرجع فقط
```

## التحديث والنشر
```
node tools/build-rules.mjs
firebase deploy --only database,hosting
```
